# Paly App Store Screenshots

Use the screenshots in `final-framed/` for App Store Connect.

- Size: 1284 x 2778 px portrait
- Sanitized app captures: `actual-edited/`
- Framed App Store export script: `final-source/export.ps1`
- Export command: `powershell -ExecutionPolicy Bypass -File app-store-screenshots/final-source/export.ps1`

The final framed screenshots use the real edited app captures inside iPhone frames, with backdrop copy added around them. The visible personal/course data is replaced with fictional names.

Original captures, editing crops, and contact sheets intentionally stay local and are ignored by Git.
